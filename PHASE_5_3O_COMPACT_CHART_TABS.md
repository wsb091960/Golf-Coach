# Phase 5.3O — Compact Chart Tabs

## What changed

- Reorganized the Charts workspace into four secondary tabs:
  - Flight Replay
  - Shot Metrics
  - Shot Pattern
  - Delivery
- Displays only one large chart panel at a time.
- Reduced the simulator canvas height and capped the chart workspace width for
  better use of widescreen displays.
- Pauses the flight replay automatically when another chart tab is selected.
- Added keyboard navigation between chart tabs with Left/Right, Home, and End.
- Preserved shot selection across every chart view.
