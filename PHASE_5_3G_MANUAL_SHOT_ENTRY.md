# Phase 5.3G — Restore Manual Shot Metric Entry

## Restored workflow

- Added **Add Shot Manually** to the Session Performance header.
- Added the same action directly inside the Shots tab.
- Restored the modal entry form for club, distance, speed, launch, spin,
  delivery, direction, apex, offline and shot-shape metrics.
- Preserved automatic Smash Factor calculation when Ball Speed and Club Speed
  are entered.
- Preserved automatic Face to Path calculation when Club Face and Club Path
  are entered.
- Preserved automatic shot-shape classification when Shot Shape is left blank.
- Saved manual shots immediately feed Overview, Charts and the Shot Table.

## Metric sign convention

- Left is negative.
- Right is positive.
- This convention applies to Start Direction, Offline, Spin Axis, Club Path,
  Club Face and Face to Path.
