# Phase 5.3L — Shot Table Dispersion Map

## What changed

The former Dispersion bar chart has been replaced by a landing-pattern map built directly from the session shot table.

- Every included shot with carry data appears as a numbered landing dot.
- Each dot uses that shot's actual carry and offline distance.
- Excluded shots do not affect the display, average or dispersion pattern.
- The currently selected shot receives a gold halo.
- Club colors help distinguish mixed-club sessions.
- A gold diamond marks the session average landing position.
- A dashed gold ellipse visualizes the session's carry and lateral spread.
- The selected-shot label shows shot number, carry and left/right offline distance.

## Visual design

The map uses a wider driving-range layout so it remains related to—but visually distinct from—the single-shot golf-hole chart:

- Wide striped landing field.
- Tee line at the bottom.
- Tree lines and rough at the sides.
- 50-yard target rings.
- 20-yard lateral guides.
